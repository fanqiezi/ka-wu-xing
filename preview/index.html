卡五星 · 手机版样张

两张样张都是假数据、不接游戏逻辑，但用的是真实牌面（同一套 SVG），所以牌就是最终效果。 手机上直接点开看；电脑上会自动等比缩放居中。

竖屏样张 · 390×844 三段式：两家对手（牌背/副露/亮倒行）→ 中央牌河+信息 → 你的听牌条+手牌+大按钮。
重点看：手牌够不够大、信息够不够、拇指好不好按。 横屏样张 · 844×390 三列：上家 | 中央（你的牌河 + 剩余张数）| 下家；底部手牌可以放得更大，按钮竖排在右侧。
重点看：横屏能不能一眼看清三家、手牌多大合适。
两张样张里都可以：点手牌（抬起 + 顶部确认条，防误触）· 长按手牌（看「打这张听什么」）· 点「亮倒」（风险确认抽屉）· 点「胡」（结算抽屉）· 顶部「记录 / 设置」· 右下角「样张设置」切换 状态（正常 / 上家亮倒 / 我亮倒）· 手牌大小（紧凑 / 标准 / 大字）· 牌河行数。
